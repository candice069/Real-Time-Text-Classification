# Publication notes

The original project README includes benchmark and quality claims (such as F1, throughput and latency reductions). Publish them as measured results only if you can attach evaluation scripts, dataset details, hardware/environment details, and reproducible logs.

Local defaults, including the Grafana example admin password in `docker-compose.yml`, must be changed before exposure to any public network.

Execution and metric results have not been verified as part of this cleanup.
